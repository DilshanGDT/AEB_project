# AEB Project – Bond Violators Management System

A web-based application developed to manage bond violators' information, financial records, payments, interest calculations, and reports for the Academic Establishment Department (AED) of ABC University.

## Tech Stack

- **Frontend:** React, Vite, TypeScript
- **Backend:** Go (Golang), Gin
- **Database:** MySQL

## Project Structure

```text
AEB_project/
├── documents/     # Excluded from Git
├── frontend/      # React + Vite application
├── backend/       # Go backend application
├── .gitignore
└── README.md
```

## Key Features

- Employee and bond violator management (CRUD).
- Bond value, recovery, and compound interest management.
- Monthly payment tracking.
- Role-based access control.
- Dashboard summaries and financial reports.
- PDF report generation.
